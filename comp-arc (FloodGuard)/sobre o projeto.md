# FloodGuard – Sistema de Alerta de Enchentes

## Sobre o projeto

O FloodGuard é um protótipo de sistema embarcado desenvolvido durante a Global Solution de 2026 da FIAP, com foco na prevenção de riscos e na comunicação de alertas relacionados a enchentes.

A proposta surgiu a partir da recorrência de enchentes no Brasil e da necessidade de soluções tecnológicas acessíveis que auxiliem a população em situações de risco.

## Objetivo

Desenvolver um sistema interativo capaz de comunicar situações de risco por meio de alertas visuais, sonoros e mensagens informativas, facilitando a compreensão das informações pelos usuários.

## Funcionamento

O sistema utiliza um Raspberry Pi Pico programado em MicroPython, integrado a componentes eletrônicos simulados na plataforma Wokwi.

A interface é composta por um display LCD que apresenta informações e um menu interativo, permitindo que o usuário navegue pelas opções utilizando botões físicos.

O protótipo também utiliza LEDs e um buzzer para representar diferentes situações de segurança e emitir alertas.

## Principais funcionalidades

- Interface interativa por meio de um display LCD 16x2.
- Navegação e seleção de opções utilizando botões físicos.
- Sinalização visual por LEDs verdes e vermelhos.
- Emissão de alertas sonoros por meio de um buzzer.
- Comunicação com o display utilizando o protocolo I2C.

## Tecnologias utilizadas

- Python (MicroPython)
- Raspberry Pi Pico
- Wokwi
- Protocolo de comunicação I2C
- Sistemas embarcados
- Internet das Coisas (IoT)

## Conhecimentos aplicados

O desenvolvimento do projeto permitiu aplicar conhecimentos de lógica de programação, arquitetura de computadores, integração entre hardware e software, comunicação entre componentes eletrônicos e desenvolvimento de interfaces interativas.
