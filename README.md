# Citizen Assist AI

## Sobre o projeto

O Citizen Assist AI é um projeto acadêmico desenvolvido durante a Global Solution do segundo semestre de 2026, no curso de Ciência da Computação da FIAP.

O projeto tem como objetivo desenvolver soluções tecnológicas voltadas à inclusão digital, à acessibilidade e à melhoria do acesso da população aos serviços públicos.

A proposta integra diferentes áreas da computação, aplicando conhecimentos de programação, estruturas de dados, lógica computacional, análise de dados e sistemas embarcados.

## Objetivos

- Facilitar o acesso a informações sobre serviços públicos.
- Desenvolver soluções voltadas à inclusão digital.
- Automatizar processos de consulta e tomada de decisões.
- Desenvolver protótipos de sistemas de alerta.
- Aplicar conceitos computacionais na resolução de problemas sociais.

## Projetos desenvolvidos

### Gerenciamento de Serviços Públicos

Sistema desenvolvido em Python para cadastro, consulta, atualização, exclusão, pesquisa e ordenação de serviços públicos, utilizando listas simplesmente encadeadas e algoritmos implementados manualmente.

### Módulo de Decisão Lógica

Sistema de tomada de decisões baseado em lógica booleana, considerando condições de documentação, disponibilidade de atendimento e prioridade.

### FloodGuard

Protótipo de sistema de alerta de enchentes desenvolvido com Raspberry Pi Pico e MicroPython, utilizando uma interface interativa, sinalização visual e alertas sonoros.

### Análise de Inclusão Digital

Análise de dados reais sobre inclusão digital e acesso a serviços no Brasil, utilizando técnicas de processamento e análise de dados.
